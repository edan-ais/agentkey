# Contributing

Thanks for helping. Small fixes are welcome.

1. Open an issue first for anything bigger than a typo or a small fix.
2. Fork, make your change, and run the tests:
   - Node: `npm install && node --test tests/options-key.test.mjs`
   - Python: `cd packages/sdk-python && pip install cryptography pytest && pytest tests`
3. Open a pull request that explains what changed and why.

Never include real passwords, tokens or personal data in issues, tests or logs. Use throwaway logins.

By contributing you agree your work is licensed under Apache-2.0.
