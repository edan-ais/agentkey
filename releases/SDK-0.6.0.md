# SDK 0.6.0

Adds a first automatic existing-browser integration for project Playwright MCP hosts. Bare setup preserves the selected browser connection and registers AgentKey login tools, with a required MCP host restart. The local vault and owner approval remain free with no account.

This does not attach to every agent or invent browser access. Unsupported project configs remain unchanged. The host process and OS user are trusted. The wrapper excludes arbitrary evaluation, code, network/storage inspection and session export, and pauses browser tools during credential use. Completion requires exact identity evidence on the same site. Human checks are not completion.

Production acceptance and independent review results are recorded separately from this source description.
